Калькулятор риска поздних преждевременных родов

Логистическая регрессия (метод GLS)

Важно. Калькулятор воспроизводит математическую модель логистической регрессии. Результат — расчётная вероятность поздних преждевременных родов (y = 1). Не заменяет клиническое решение врача.
Осложнения и факторы риска
Антропометрия
Система автоматически переведёт значение в код от 0 до 4.
Плацентарные нарушения и развитие плода
Справочник кодировки переменных модели
Переменная Код Значение
x₁ — Преждевременный разрыв плодных оболочек 0 / 1 0 — нет, 1 — да
x₂ — Новая коронавирусная инфекция (COVID-19) 0 Не болела
2 7–12 недель беременности
3 13–27 недель беременности
4 0–6 недель или 28–40 недель беременности
Код 4 присваивается критическим периодам.
x₃ — Острая респираторная инфекция 0 / 1 0 — нет, 1 — да
x₄ — Инфекция, вызванная Ureoplasma, Mycoplasma, Toxoplasma или Chlamidia 0 / 1 0 — нет, 1 — да
x₅ — Инфекция мочевыводящих путей, МКБ 0 / 1 0 — нет, 1 — да
x₆ — Угроза прерывания беременности 0 / 1 0 — нет, 1 — да
x₇ — Код ИМТ
(индекс массы тела) 		0 18,5 ≤ ИМТ ≤ 25 кг/м²
1 16 ≤ ИМТ < 18,5 кг/м² или 25 < ИМТ ≤ 30 кг/м²
2 ИМТ < 16 кг/м² или 30 < ИМТ ≤ 35 кг/м²
3 35 < ИМТ ≤ 40 кг/м²
4 ИМТ > 40 кг/м²
Границы соответствуют кодированию, использованному при расчёте модели.
x₈ — Другие плацентарные нарушения 0 / 1 0 — нет, 1 — да
x₉ — Недостаточный рост плода, требующий предоставления медицинской помощи матери 0 / 1 0 — нет, 1 — да
Последовательность факторов:
x₁ — преждевременный разрыв плодных оболочек;
x₂ — новая коронавирусная инфекция;
x₃ — острая респираторная инфекция;
x₄ — инфекция, вызванная Ureoplasma, Mycoplasma, Toxoplasma или Chlamidia;
x₅ — инфекция мочевыводящих путей, МКБ;
x₆ — угроза прерывания беременности;
x₇ — код ИМТ;
x₈ — другие плацентарные нарушения;
x₉ — недостаточный рост плода.

Целевая переменная: y = 1 — поздние преждевременные роды, y = 0 — доношенные роды.
Метод построения модели: пошаговая логистическая регрессия GLS, пакет Statistica.
Качество модели: AUC = 0,8244. Порог по индексу Юдена: 0,424399.
